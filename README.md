# kodfilm — кино из кода

Собственный движок для 3D-короткометражек: Three.js (WebGL) + headless Chromium + ffmpeg.
Всё бесплатно, рендер идёт на серверах GitHub Actions.

## Как устроено
- `films/*.js` — фильм: длительность, fps, титры, сцена и функция `update(t)`. Время задаётся номером кадра, поэтому рендер детерминированный и режется на куски.
- `engine/` — рантайм: рендерер, bloom, плёночный грейд (зерно, виньетка, аберрация), титры, каше 2.39:1.
- `render.mjs` — гонит кадры из браузера в ffmpeg (H.264, CRF 17).

## Объектив и затвор (общие для всех стилей)
- `studio/crew/lens.json` — числа камеры в одном месте: сенсор Super 35, целевое размытие фона и минимальная глубина резкости по крупности плана, затвор 180°, правило числа подкадров. Их читают и Blender-ядро (`studio/gaffer.py`, `studio/film.py`), и JS-движок, поэтому превиз и чистовой рендер не расходятся.
- `engine/lens.js` — фокусное из угла обзора, диафрагма по крупности плана (та же формула, что `gaffer.fstop_for`), кружок нерезкости в пикселях, число подкадров: столько, чтобы копии движущегося объекта шли не реже чем через 8 пикселей (иначе фара на проезде распадается на копии). `makeShutter` ставит подкадры: момент внутри затвора, сдвиг на долю пикселя, точка на зрачке объектива, фокус на субъекте, и отдаёт кружок нерезкости подкадра для досглаживания.
- `engine/accum.js` — кадр из n подкадров (не меньше 16: каждый подкадр — ещё и отсчёт сглаживания тонкого) и в каждом подкадре два фильтра, которые сливают копии соседних подкадров: досглаживание по кружку нерезкости радиусом в шаг между копиями на зрачке (боке у объектива — пятно, а не пучок линий) и реконструкция размытия движения (McGuire и др., 2012: передний план размазывается и на фон за ним). Веса в обоих — плотность размазанной точки, поэтому яркость сохраняется: тонкий стебель в смазе не превращается в отдельные линии. Объекты, которые движутся сами, помечаются `markMoving`.
- Как включить в фильме: план из `build()` отдаёт `subframes(t) → { n, pose }`. Пример: `films/lens_test.js`.

## Рендер на GitHub
Actions → **Render film** → Run workflow. По умолчанию 4K (3840×2160), 60 fps, 12 параллельных кусков.
Готовый `film.mp4` лежит в артефактах запуска.

## Локально
```
npm install && npx playwright install chromium
node render.mjs --w 1280 --h 720 --out out/preview.mp4
node render.mjs --stills 120,600,1200      # стоп-кадры для проверки
node render.mjs --film films/lens_test.js --stills 30,50   # проверка затвора: фара штрихом, фон в боке
```
